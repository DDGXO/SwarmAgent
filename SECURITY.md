## Reporting a Vulnerability

The SwarmAgent team takes the security of our tools and runtime integrity seriously.

If you identify a security vulnerability:
* **Do NOT report security vulnerabilities via public GitHub issues.**
* Submit vulnerability details via HackerOne to handle: `pintuback`.
* Alternatively, contact the maintainers directly via private security channels.

### Please include in your report:
* Type of issue (e.g., Arbitrary File Write via Cheerio persistence, Command Injection, WebSocket hijacking).
* Detailed reproduction steps with sample payloads.
* Potential attack scenario and impact assessment.
* Suggested fix or patch if available.

### Disclosure Policy
We ask that you follow responsible disclosure guidelines. We will acknowledge receipt of your vulnerability report within 24 business hours and keep you updated on progress towards mitigation before any public disclosure.
